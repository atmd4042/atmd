توضح هذه السياسة كيفية تعامل متجر ATMD وتطبيقه على Android مع المعلومات الشخصية عند استخدام المتجر أو إنشاء حساب أو إرسال طلب. نستخدم المعلومات بالقدر اللازم لتشغيل الحساب وإدارة الطلبات والتواصل مع العميل.

المعلومات التي نجمعها

عند إنشاء الحساب واستخدام التطبيق، نجمع المعلومات التي يقدمها المستخدم، وتشمل:

  • الاسم.
  • عنوان البريد الإلكتروني.

تُستخدم هذه المعلومات لإنشاء الحساب وإدارته، ومعالجة الطلبات ومتابعتها، والتواصل مع العميل بشأن الحساب أو طلباته.

مشاركة المعلومات

لا نشارك المعلومات الشخصية إلا بالقدر اللازم لتقديم الخدمة أو تنفيذ الطلب. وقد نشارك المعلومات ذات الصلة مع مزودي خدمات الدفع أو التوصيل عند الحاجة، ليتمكنوا من أداء الخدمة المطلوبة. ويخضع تعامل هؤلاء المزودين مع المعلومات لسياساتهم وشروطهم.

الاحتفاظ بالمعلومات وحمايتها

نحتفظ بالمعلومات ما دامت لازمة لإدارة الحساب والطلبات والتواصل، أو للوفاء بالالتزامات النظامية. نتخذ تدابير مناسبة لحماية المعلومات، لكن لا يمكن ضمان أمان أي وسيلة نقل أو تخزين إلكترونية بصورة مطلقة.

طلبات الوصول أو التصحيح أو الحذف

لطلب الوصول إلى معلوماتك أو تصحيحها أو حذفها، أرسل رسالة إلى atmd4042@gmail.com من بريدك المسجل، مع توضيح طلبك. قد نحتاج إلى التحقق من هويتك قبل تنفيذ الطلب، وقد نحتفظ ببعض المعلومات عندما يلزم ذلك للوفاء بالتزامات نظامية أو لمعالجة الطلبات.
